# Resume Builder

A modern, responsive resume builder web application built with React, Vite, and Tailwind CSS.

## Features

- Dynamic resume templates
- Real-time preview and customization
- Clean, responsive dashboard

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Icons:** Heroicons

## Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mansiuttamvaze18-wq/Resume-Builder.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
